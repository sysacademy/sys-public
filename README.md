# SYS Public

Claude plugins from Systemize Your Success, free for anyone to use.

There are no plugins here yet. They'll show up here as we add them.

## Add it to Claude Code

In Claude Code, type:

```
/plugin marketplace add sysacademy/sys-public
```

Then type `/plugin` to see what's here and install what you want.

To pick up new plugins and changes later:

```
/plugin marketplace update sys-public
```
